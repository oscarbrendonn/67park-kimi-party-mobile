# 67 Park party pack (mobile)

Live: https://oscarbrendonn.github.io/67park-kimi-party-mobile/

mobile build of 67 Park with the party pack layered on top of the original export (67park-kimi-mobile, untouched):
springy jump and landing squash, punches and throws that knock other players back, grab and throw,
a kickable park ball, jump pads, synthesized sound effects, haptics and a settings panel.

Companion build: https://oscarbrendonn.github.io/67park-kimi-party/

All pack code lives in app/party/ plus three one-line hooks in index.html and app/main.js.
